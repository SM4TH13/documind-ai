# DocuMind AI

## Description

DocuMind AI est une application Full Stack permettant d'importer des documents (PDF, DOCX, TXT) et de poser des questions grâce à l'API OpenAI.

Les réponses sont générées uniquement à partir du contenu des documents (RAG).
